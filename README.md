# MercApp

Sistema ecommerce con chatbot IA usando Flask + Ollama.

---

## Características

- Chatbot con IA local usando Ollama
- Sistema ecommerce
- Login y registro
- Productos y tiendas
- Frontend con HTML/CSS/JS
- Backend Flask
- Arquitectura modular

---

## Tecnologías

- Python
- Flask
- Ollama
- Llama 3.2
- HTML
- CSS
- JavaScript
- SQLite
